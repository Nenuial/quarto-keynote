# Keynote theme reference

What every class, attribute and script in the `keynote` extension does, and where new styles belong.
Slides are 1280 × 720 px. The examples are Quarto markdown.

## Files

| File | Role |
|---|---|
| `_extensions/keynote/global.scss` | Fonts, headings, footer and logo, small utility classes, boxes, quotes, code |
| `_extensions/keynote/letterbox.scss` | The letterbox frame around the slide (anything that overflows it is clipped at its outer edge), and full-bleed images and backgrounds that cover it |
| `_extensions/keynote/custom-callouts.scss` + `custom-callouts.lua` | Extra callout types (`callout-paper`, `callout-women`, …) |
| `_extensions/keynote/infographic.scss` | Infographic layouts: profile slides with key numbers, chapter openers, cards, facts, captions, quiz, line charts, and the frame of interactive canvases |
| `_extensions/keynote/theme.html` | Scripts run after the slides load (backgrounds, footer and logo, print view, count-up, accents) |
| `_extensions/keynote/codewindow/` | Bundled codewindow plugin (code blocks in a macOS-style window) |
| `_extensions/keynote/palettes/<name>.scss` | One palette per theme: colors only |
| `_extensions/<name>-key/` | Generated by `generate-themes.sh` from each palette. Do not edit. |
| `infographic.qmd` | Demo deck of the infographic layouts. Render it with `quarto render infographic.qmd --to pomogreen-key-revealjs` to check a palette. |

## Where a new style goes

- **Structure** (layout, sizes, spacing, behaviour) goes in `keynote/*.scss` or `theme.html`. It uses only palette variables (`$body-bg`, `$body-color`, `$presentation-heading-color`, …) or the CSS custom properties below, never a literal theme color.
- **Theme** (colors) goes in `palettes/<name>.scss`. A palette sets the base colors and can override any `!default` variable, such as the `$info-*` ones.
- **Deck-specific** styles stay in the deck (in GeoKey, each deck's `resources/` folder, such as `2-Solar_System/resources/solar.css`, and `DF-Cosmology/resources/cosmos.css` for styles shared by the decks of one chapter). This covers styles tied to one subject (planet colors, the starfield, the "journey" line), one-off diagrams, and simulations whose JS lives in the deck.

When a deck-specific style is needed by a second deck, generalise it (give it a subject-neutral name and use the tokens) and move it here.

## Palette variables

A palette sets `$body-bg`, `$body-color`, `$link-color`, `$selection-bg`, `$selection-color` and `$presentation-heading-color`. Everything else is derived in `global.scss` or `infographic.scss` and can be overridden in the palette:

| Variable | Default | Used for |
|---|---|---|
| `$code-bg`, `$codewindow-bg` | darker `$body-bg` | Code blocks, codewindow |
| `$light-bg-*`, `$dark-bg-*` | dark and light tone of the palette | Text on slides with a light or dark background |
| `$box-bg` | `$body-bg` at 60 % | `.box` |
| `$danger-color` | `#D9534F` | `span.danger` |
| `$border-leftright-width`, `$border-updown-width` | 80px, 40px | Letterbox frame |
| `$info-accent` | `$presentation-heading-color` | `--accent` |
| `$info-muted` | `$body-color` at 60 % | `--muted` |
| `$info-panel` | `$body-color` at 7 % | `--panel` |
| `$info-overlay` | darkened `$body-bg` at 80 % on dark palettes, `$body-bg` at 88 % on light ones | `--overlay` |
| `$info-overlay-color` | `$body-color` | `--overlay-text` |
| `$info-ghost` | `$body-color` at 7 % | `--ghost` |
| `$info-on-accent` | the darker of `$body-bg` and `$body-color` | `--on-accent` |

`lumina` and `nord` override `$info-panel`, `$info-overlay`, `$info-overlay-color` and `$info-ghost` to the values the Solar System deck was designed with.

## Infographic tokens (CSS custom properties)

Set on `.reveal` from the `$info-*` variables. Any slide or box can redefine them.

| Property | Meaning |
|---|---|
| `--accent` | Highlight color: titles, key numbers, borders, bullets of a box |
| `--muted` | Secondary text (labels, kickers, questions) |
| `--panel` | Translucent fill of cards, stats and takeaways |
| `--overlay` | Near-opaque fill of boxes that sit over images or canvases (facts, captions) |
| `--overlay-text` | Text color in those boxes |
| `--ghost` | The large watermark number of `.part` slides |
| `--on-accent` | Text on accent-colored fills (`.bar` segments) |

To change the accent:

```markdown
## Mars {.profile accent="#e5774a"}        <!-- whole slide -->
::: {.card accent="#dcaa74"}                <!-- one box -->
```

`accent="…"` becomes `data-accent`, and `theme.html` copies it into `--accent`. `style="--accent: …"` works too. A deck can also set accents from its own attributes in CSS, as the Solar System deck does with `section[data-body="mars"] { --accent: … }`.

## Infographic classes (`infographic.scss`)

### Profile slide: `.profile`

A big accent-colored title, a one-line kicker, a tagline, 2 × 2 key numbers, a fun fact, and a large cut-out image on the right that slides in. It is meant for a planet, a country, a city or a person.

```markdown
## Mars {.profile accent="#e5774a"}

::: {.kicker}
Planet 4 · Rocky
:::

::: {.tagline}
The red planet
:::

::: {.hero}
![](images/planet_mars.png)
:::

::: {.stats}
...see .stats...
:::

::: {.fact .fragment}
...
:::
```

| Class | Effect |
|---|---|
| `section.profile` | Title 80px in `--accent`, no underline |
| `.kicker` | Small uppercase muted line under the title |
| `.tagline` | Italic line, 34px |
| `.hero` | Image in the top right, 640px wide, partly off the slide, behind the text, with an accent glow. It animates in each time the slide is shown, but not in print. Use a transparent cut-out PNG (a planet, a map shape), not a rectangular photo. |
| `.hero.wide` | 900px, lower (for wide objects such as Saturn) |
| `.hero.small` | 520px, closer to the edge |
| `.hero.fade` | The edges of the image fade out: for a photo on a dark background (a galaxy, a nebula) that is not a cut-out |

A hero can take `.lightbox` (`![](images/mars.png){.lightbox}`): the text blocks only take their own width, so clicks next to them reach the image.

To place a hero elsewhere, add `style="position: relative; right: auto; top: 30px; width: 100%;"` (for example in a column).

### Key numbers: `.stats` › `.stat`

A grid of number tiles. The first paragraph holds the number and its unit, the next ones the label.

```markdown
::: {.stats}
::: {.stat}
[687]{.num} [days]{.unit}

one year
:::
::: {.stat}
[1848]{.num .no-count}

federal state
:::
:::
```

| Class | Effect |
|---|---|
| `.stats` | Grid of 2 columns of 300px |
| `.stats.three` | 3 columns of 300px |
| `.stats.wide` | 3 equal columns over the full width, bigger numbers (64px) |
| `.stat` | Tile: `--panel` fill, 3px `--accent` top border |
| `.num` | The number, 44px in `--accent`, tabular figures. It counts up from 0 each time the slide is shown (`theme.html`), keeping its format: `1 300`, `0.38`, `−60`. Text that is not a plain number (`24 h 37`, `1/3`) is left alone. |
| `.num.no-count` | Never counts (years, codes) |
| `.unit` | Unit after the number, 24px |

To change the grid of one slide, use for example `style="grid-template-columns: repeat(2, 330px);"`.

### Fun fact: `.fact`

A box with an accent left border and a "Did you know?" heading. Use `**bold**` inside for accent-colored words.

```markdown
::: {.fact .fragment}
Mars has the **highest volcano** in the Solar System.
:::
```

| Class or attribute | Effect |
|---|---|
| `.fact` | "Did you know?" box on `--overlay`, max 618px wide |
| `.fact.answer` | Heading "Answer" (for a question asked earlier) |
| `label="…"` | Custom heading: `::: {.fact label="Record"}` |

The headings follow the deck's `lang:` (`fr`: "Le savais-tu ?" / "Réponse", `de`: "Schon gewusst?" / "Antwort", otherwise English).

### Chapter opener: `.part`

A section start with a big translucent number, a large title, a guiding question and an image on the right.

```markdown
## The rocky planets {.part part="02"}

::: {.question}
Venus is almost twice as far from the Sun as Mercury. So why is it hotter?
:::

::: {.part-img}
![](images/rocky_planets.png)
:::
```

| Class or attribute | Effect |
|---|---|
| `section.part` | Title 80px, 230px from the top, no underline |
| `part="02"` | Watermark number in the top left, in `--ghost` |
| `.question` | Italic muted text with an accent "Question:" prefix (`fr` "Question :", `de` "Frage:", or `label="…"`) |
| `.part-img` | Image in the top right, 520px wide, behind the text. Adjust it with `style="width: 380px; top: 140px; right: 80px;"`. |
| `.part-img.fade` | The same, with fading edges (see `.hero.fade`) |

### Cover title slide: `title-slide-attributes`

A title slide in the style of the chapter openers: a picture on the right of the letterbox that fades into the slide, a large title in an accent colour with a short bar, the subtitle as a spaced kicker, and the author and date in muted type. It is switched on from the front matter:

```yaml
title-slide-attributes:
  data-cover: images/head_atmosphere.png
  data-cover-accent: "#7ec8ff"
  data-cover-blend: lighten
```

| Attribute | Effect |
|---|---|
| `data-cover` | The picture, relative to the deck: a 2:3 portrait fills a 600 × 800 px frame on the right. `theme.html` adds the class `.cover` to `#title-slide`. List the picture under `resources:`, since only the script uses it. |
| `data-cover-accent` | Colour of the title and its bar (default `--accent`) |
| `data-cover-blend` | A `background-blend-mode` against the slide colour: `lighten` makes the black of a photo (space, night) take the slide colour |

### Cards: `.cards` › `.card`

Side-by-side boxes for definitions, comparisons and moons.

```markdown
::: {.cards style="--n: 3;"}
::: {.card}
[Io]{.ttl}
[400]{.big}
active volcanoes
:::
::: {.card .fragment accent="#a3be8c"}
[Europa]{.ttl}

- an ocean under the ice
- twice as much water as Earth
:::
:::
```

| Class | Effect |
|---|---|
| `.cards` | Grid of `--n` equal columns (default 3), gap 18px |
| `.card` | `--panel` fill, `--accent` top border, 22px text. Lists are indented inside the box. |
| `.ttl` | Card title, 30px in `--accent`. Use the span `[Title]{.ttl}`, not a `###` heading: a heading inside a div starts a new slide. |
| `.big` | A big accent number or word, 44px |

Images inside a card take its full width.

### Takeaway: `.takeaway`

A full-width line that sums up the slide, starting with an accent arrow (➜).

```markdown
::: {.takeaway .fragment}
Far from the Sun it is cold enough for **ice** to form.
:::
```

### Composition bar: `.bar`

A 618px stacked bar. Each segment is a span with its own width and color, and its text in `--on-accent`. It works as raw HTML or as markdown spans.

```markdown
::: {.bar}
<span style="width: 73.5%; background: #f5a623;">Hydrogen 73.5 %</span><span style="width: 24.9%; background: #ffd27a;">Helium 25 %</span>
:::
```

### Photo caption: `.caption`

A box in the bottom left over a full-slide photo, with a blurred `--overlay` background so it stays readable on any image. Its colors are fixed, so they are not affected by Reveal's `has-light-background` text color.

```markdown
## Hale-Bopp {.no-title .no-footer .no-logo background-image="images/comet.png" background-size="cover"}

::: {.caption}
[Hale-Bopp]{.ttl}
In 1997, it was visible to the naked eye for a record **18 months**.
:::
```

| Class | Effect |
|---|---|
| `.caption` | 22px text, max 600px wide |
| `.caption.small` | 18px text, less padding |
| `.ttl` (inside) | Title in `--accent`, 34px |

### Quiz: `.clues` + `.reveal-answer`

A "Who am I?" slide: the clues appear one by one, then the answer appears on the right.

```markdown
## Who am I?

::: {.clues .incremental}
* I spin backwards.
* I am the hottest planet.
:::

::: {.reveal-answer .fragment}
![](images/planet_venus.png)
Venus
:::
```

| Class | Effect |
|---|---|
| `.clues` | 30px list with spacing |
| `.reveal-answer` | Box in the top right, 400px, 44px accent text. The image inside is 340px wide. |

### Interactive canvas: `.sim` › `.sim-controls`

The frame of a simulation whose script lives in the deck (orbits, expanding space…). The script appends a canvas and a control bar to an empty `.sim` div, and runs its animation only while the slide is shown.

```markdown
## Space is stretching

::: {.sim .expansion}
:::
```

| Class | Effect |
|---|---|
| `.sim` | 1280 × 610 box under the title; its canvas fills it |
| `.sim-controls` | Control bar in the bottom left, on `--overlay`: buttons with an accent border, accent-coloured sliders and checkboxes |
| `.sim-controls .rate` | Accent readout next to a slider (e.g. "1 s = 4 weeks") |
| `.sim-controls .date` | Muted line on its own row, for the state of the simulation; `<b>` inside is in the accent |

The scripts in the GeoKey Cosmology decks (`2-Solar_System/resources/sims.js`, `1-Universe/resources/sims.js`, `3-Earth/resources/sims.js`) show the pattern. The canvas is drawn at 2× resolution. Buttons lose their focus after a click, so the space bar still moves the slides. The animation stops when the slide is left.

### Line charts: `svg.chart`

An inline SVG chart, written in the slide or built by a deck script. Draw it in the `viewBox` units: the chart takes the width of its box.

```markdown
<svg class="chart" viewBox="0 0 580 340">
  <path class="ax" d="M70,30 L70,290 L560,290"/>
  <line class="grid" x1="70" y1="160" x2="560" y2="160"/>
  <g class="fragment">
    <path class="curve draw" pathLength="1" style="stroke: var(--accent);" d="M70,290 L200,120 L540,80"/>
    <text class="lbl" x="536" y="66" text-anchor="end" style="fill: var(--accent);">Measured</text>
  </g>
</svg>
```

| Class | Effect |
|---|---|
| `svg.chart` | Block, 100% wide, overflow visible (labels may stick out of the `viewBox`) |
| `.ax` | Axis line in `--muted`, 2px |
| `.grid` | Grid line, body color at 12% |
| `text` | 16px `--muted` text; `.lbl` 18px semibold, `.big` 22px semibold in the body color |
| `.curve` | 4px round line, no fill; color it with `style="stroke: …"`. `.dashed` for a dashed one. |
| `.curve.draw` | With `pathLength="1"`, inside a `.fragment`: the curve draws itself in 2.2 s when the fragment appears (drawn at once in print) |
| `.area` | Filled shape without a stroke (e.g. the gap between two curves) |

A deck can change the text sizes for one chart (`.reveal .rotation text { font-size: 15px; }`).

## Other classes (`global.scss`, `letterbox.scss`)

### Slides

| Class | Effect |
|---|---|
| `.no-title` | Hides the slide's `h1`/`h2` (it stays in the menu and the URL) |
| `.no-footer`, `.no-logo` | Hide the footer or the logo on that slide, on screen and in print |
| `.scroll-page` | Scroll view: the footer and logo are placed inside the page |

### Text

| Class | Effect |
|---|---|
| `.chapter` | Centered heading with a `$body-color` underline (title slides) |
| `.all-caps` | Uppercase |
| `.underline` | 2px underline |
| `.center`, `.center-70p` | Centered text; a 70 % centered block |
| `span.danger` | `$danger-color` |
| `span.term` | Blue term |
| `.kbd` | Keyboard key |
| `.symbol` | Fira Code font |
| `.title`, `.dateplace` | Big title and date line of custom title slides |
| `.title > p > strong.blur` | Word that blurs out over 3 s |

### Layout

| Class | Effect |
|---|---|
| `.v-align` | Flex, centers its content vertically in 90 % of the slide height |
| `.v-center`, `.v-center-bottom`, `.v-right` | Flex rows aligned at the bottom: centered or to the right |
| `.v-fill` | `height: 100%` |
| `.pull-left`, `.pull-right` | Floating half-width columns |
| `.row` | 10px top margin |
| `.cell` | Full-width code cell; `.cell-output` gets a framed, smaller output |

### Boxes and quotes

| Class | Effect |
|---|---|
| `.box` | Rounded panel in `$box-bg` (translucent background color), to put text over an image |
| `.box.opaque` | The same, opaque |
| `.box-blond` | Rounded cream panel |
| `.quote-box` + `.author` | Speech-bubble quote with its author below, in `$selection-color` |
| `.blur` | Blurred and faded. `.fragment.blur` starts blurred and turns sharp when it appears. |

### Images

| Class | Effect |
|---|---|
| `.image-left`, `.image-right` | Full-height 2:3 image at the edge of the letterbox, cropped to fill (title and chapter slides) |
| `.left-half`, `.right-half` | Image covering half of the letterbox |
| `.left-top-quarter`, `.left-bottom-quarter`, `.right-top-quarter`, `.right-bottom-quarter` | Image covering a quarter |
| `.full-frame` | Iframe or content covering the whole letterbox |
| `.image-cover` | Image cropped to fill its box |
| `.drop-shadow` | Shadow under the images inside |
| `.no-caption` | Hides figure captions |
| `img.icon` | Inline icon at text height |
| `img.sticker-float-right`, `-left`, `-midright` | 160px sticker floating in the top corner |

### Callouts

`::: callout-paper`, `callout-women`, `callout-link`, `callout-question`, `callout-pro`, `callout-con`, with `title="…"`. The colors and icons are defined in `$custom-callouts` (in `custom-callouts.scss`), and a palette can override that list.

## Scripts (`theme.html`)

| Script | What it does |
|---|---|
| Backgrounds | Moves `background-color`, `background-image`, `background-video` and `background-iframe` from Reveal's background layer into the slide (`.background-*-div`), so they fill the letterbox and not the whole window. Background videos get controls. |
| Controls | Moves the menu button, progress bar, slide number, footer and logo inside `.slides`, so they sit in the letterbox |
| References | A reference list (`#refs`) taller than the slide is split over several slides with the same title and a page count (`References 1/2`), instead of scrolling; the slide menu and PDF export get every page, and `#/references-2` links to the second |
| Print frame | In print view (`?print-pdf`), copies the footer and logo onto every page, except on `.no-footer` or `.no-logo` slides |
| `no-footer`, `no-logo` | Hide the footer and the logo while such a slide is shown |
| Cover title slide | With `title-slide-attributes: data-cover`, adds `.cover` to `#title-slide` and sets `--cover-img` (absolute URL), `--cover-accent` and `--cover-blend` |
| Iframe embedding | Inside an iframe, hides the footer and the logo and turns off the scroll view |
| Accents | `accent="#hex"` on any element sets its `--accent` |
| Count-up | `.stat .num` counts up when its slide is shown (see `.stats`); not in print or in a hidden tab |

## Workflow

- **New theme:** add `palettes/<name>.scss` with a `// title:` comment, then run `./generate-themes.sh`.
- **New shared file:** add it to the `theme:` list in `keynote/_extension.yml`, `generate-themes.sh` and `sync-shared.sh`. Also add it to the `theme:` lists of `quarto-lddr` and `quarto-swissequestrian`, which use `keynote/<file>`.
- **Release:** bump `version` in `keynote/_extension.yml`, then run `./generate-themes.sh` and `./sync-shared.sh`. Commit here and in the LDDR and SE repositories, then push. The GeoKey decks pick up the release with `quarto update nenuial/quarto-keynote`.
